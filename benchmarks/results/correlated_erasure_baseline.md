# Correlated-erasure baseline: the brickwork ring against the literature

Generated by `benchmarks/correlated_erasure_baseline.py` on 2026-10-16 (AMD Ryzen 9 9950X3D 16-Core Processor, 32 threads, sparsegf2 3.0.0.dev12); 17.1 minutes. Physics checks with exact answers (the J -> inf intervals, J = 0, the samplers, the random-code formula) are in `tests/test_brickwork_correlated.py`.

**Protocol.** Ring `cycle(n)`, `schedule="matching"` (brickwork), uniform two-qubit Cliffords, Z measurements at rate p after every layer, 4n layers, purification picture, final layer. n = [32, 64, 128, 256] (and [512, 1024] for the contiguous lengths only), p = [0.04, 0.08, 0.12, 0.3]; 256 trajectories per ring (n, p), 64 per Watts-Strogatz (β, n, p). Seeds: `run(seed=[20261016, family, n, round(1000 p), round(100 β)])`, family 0 = ring, 1 = Watts-Strogatz, whose graph i is `watts_strogatz(n, 4, β, seed=[20261016, n, round(100 β), i])`. Probe `correlated_erasure(couplings=[0.0, 0.5, 1.0, 2.0], samples=100)` (ring: exact sampler, every size); uniform P_C(m) also from `erasure_first_failure(samples=200)` with `uncorrectable_region_counts(max_size=exhaustive_cutoff(n, 50000))`. Means over codes with k > 0 unless said; ± is one standard error.

* **Definitions matter:** at n = 1024, p = 0.08, |A|* = 28.1 ± 0.7 (mean information crosses 1 bit), ⟨l⟩ = 29.4 ± 0.5 (shortest failing interval through a site), d_cont = 17.1 ± 0.6 (shortest failing interval anywhere): Li-Fisher's crossing tracks the site-averaged length, not the per-code minimum. Li and Fisher average depths 6L-8L and reach L = 1024; this run uses depth 4n (Gullans-Huse's) and n <= 1024, so effective exponents at these sizes are compared.
* **d < d_cont (new numbers for Li-Fisher's inequality d <= d_cont):** at p = 0.08, among the codes whose distance d the exact counts and orderings pin down (low = high), the fraction whose smallest uncorrectable set is not an interval: n = 32: 0.41 (d known for 100% of the codes), n = 64: 0.51 (d known for 84% of the codes), n = 128: 0.38 (d known for 32% of the codes), n = 256: 0.32 (d known for 18% of the codes). Those codes are the ones with small d, so this is not the fraction over all codes; for the rest the bounds leave d between d low (the exact counts' cutoff plus one) and d high (the smallest of the orderings' first failures, a weak bound that grows like n here).
* **p = 0.12, an open question:** the n >= 128 exponent of |A|* is 0.46 ± 0.01 (χ²/dof 0.9), 5.2 σ above Li-Fisher's 0.38 (their single value for p = 0.04-0.12). Two possible causes are not tested here: a near-critical crossover (correlation length (p_c - p)^-ν ≈ 63 sites) and the shallower depth (4n here, against their 6L-8L). The last local slope of |A|* (n = 512 to 1024) is 0.39 ± 0.05, 1.2 σ from 0.46 and 0.3 σ from 0.38, so it is consistent with either value.
* **⟨l_min⟩ against ⟨l⟩:** Gullans-Huse find that ⟨l_min⟩ (here d_cont) scales like ⟨l⟩; the exponent of d_cont minus that of ⟨l⟩ (n >= 128) is p = 0.04: +0.04 (+1.7 σ), p = 0.08: +0.04 (+1.4 σ), p = 0.12: +0.04 (+1.4 σ).
* **New: clustered erasures hurt the brickwork codes.** From J = 0 to J = 2 the mean P_{C,J}(m) rises by more than 2 standard errors in 44 of 72 (n, p, m) cells of the selected sizes (k > 0), by as much as 0.627 (n = 256, p = 0.04, m = 32: 0.204 -> 0.831); along J = 0, 0.5, 1, 2, inf no step falls by more than 2 standard errors in 288 of 288 steps. At m = n/2 the mean does not rise from J = 0 to 2 (it falls, within 2 standard errors): n = 32, p = 0.08, m = 16: 0.9996 -> 0.9991 (-1.2 standard errors); n = 32, p = 0.12, m = 16: 0.9446 -> 0.9385 (-0.8 standard errors); n = 128, p = 0.12, m = 64: 0.9991 -> 0.9988 (-0.6 standard errors). ε_δ(J) falls with J (section 5). The permutation-invariant control (all-to-all circuits, `tests/test_brickwork_correlated.py`) shows no J dependence, as it must.
* **New: uniform against clustered erasures at n = 256** (no published monitored-circuit numbers exist to compare): P_{C,J}(m) for J = 0 / 1 / 2 / inf at the selected size where J = 0 is nearest 0.3, p = 0.04, m = 32: 0.204 / 0.425 / 0.831 / 1.000; p = 0.08, m = 32: 0.049 / 0.096 / 0.292 / 0.951; p = 0.12, m = 64: 0.134 / 0.294 / 0.591 / 0.978. A finite J stays far from the interval limit at large n (section 4: at n = 256, m = 64 a region drawn at J = 2 is one interval with probability 1.7e-10; one interval and the two-run regions weigh the same at J_x = 4.35, which grows like ln n).
* **Tolerance, n = 64, p = 0.08:** ε_0.01 = 0.0275 ± 0.0032 (J = 0, independent erasure) against 0.0174 ± 0.0012 (J = inf, one interval of Bin(n, ε) qubits); ε_0.1 = 0.1241 ± 0.0039 (J = 0, independent erasure) against 0.0617 ± 0.0019 (J = inf, one interval of Bin(n, ε) qubits).
* **Tolerance, n = 128, p = 0.08:** ε_0.01 = 0.0346 ± 0.0062 (J = 0, independent erasure) against 0.0163 ± 0.0014 (J = inf, one interval of Bin(n, ε) qubits); ε_0.1 = 0.1402 ± 0.0046 (J = 0, independent erasure) against 0.0497 ± 0.0017 (J = inf, one interval of Bin(n, ε) qubits).
* **New: the tolerances move apart with n.** ε_0.1 from n = 64 to 128: p = 0.04 (J = 0: 0.070 -> 0.085, J = inf: 0.040 -> 0.032); p = 0.08 (J = 0: 0.124 -> 0.140, J = inf: 0.062 -> 0.050); p = 0.12 (J = 0: 0.167 -> 0.210, J = inf: 0.087 -> 0.077). Under independent erasure the tolerance grows with n (two sizes only; consistent with a finite erasure threshold despite a sub-extensive distance, the degeneracy Gullans and Huse point to); under one interval of Bin(n, ε) qubits it shrinks, as an interval of about εn qubits outgrows the contiguous lengths, which grow sub-linearly (section 2).
* **Watts-Strogatz contrast (n = 256, p = 0.12):** β = 0.1, m = 64: label ring J = 0 / 2 / inf 0.349 / 0.680 / 0.884, interaction graph J = 0 / 2 0.341 / 0.922; β = 1, m = 64: label ring J = 0 / 2 / inf 0.598 / 0.593 / 0.584, interaction graph J = 0 / 2 0.590 / 0.871. At β = 1 the labels carry no geometry, so erasures clustered on the label ring see a nearly relabeling-invariant ensemble and P does not move with J; on the circuit's own interaction graph clustering still hurts.
* **Could not be compared:** the amplitudes of the lengths (figures only in the papers), p_c itself (no I3 crossing is run here), and any random-region (J = 0) or correlated-erasure statistic of monitored brickwork codes (none found in the literature survey of `docs/observables/correlated-erasure.md`, section 11). The random-code formula of Gullans et al. is checked in `tests/test_brickwork_correlated.py` instead, with its own definition of failure, 1 - E[2^-I(A:R)].

## Definitions, kept apart

* Failure here is F_C(A) = 1[I(A:R) > 0] (some logical information is lost). Gullans, Krastanov, Huse, Jiang and Flammia (PRX 11, 031066, 2021) define the failure probability as 1 - E[2^-I(A:R)] (one minus the optimal recovery probability, their Eqs. 18 and 23); at the critical size of a random [[64, 32]] code theirs is 0.390 and ours 0.711, from the same random-matrix rank law.
* d_cont (smallest failing interval) is Li-Fisher's algebraic contiguous distance and Gullans-Huse's l_min; Li-Fisher's numbers are for \|A\|*, the crossing of the mean information; Gullans-Huse's ⟨l⟩ averages the shortest failing interval through each site.
