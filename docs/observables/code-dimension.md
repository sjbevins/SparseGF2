# Code dimension

How SparseGF2 computes $k_C = S(R)$, the number of logical qubits the system
still protects, and why the ensemble engine reads it as a popcount.

The setting and notation are those of
[random-region-erasure.md](random-region-erasure.md) §1.1. The lost
information of a region is in [lost-information.md](lost-information.md).
Function references are `path::function`, relative to `src/sparsegf2/`. This
describes version 3.0.0.dev12.

## 1. Definition

The system qubits $[n]$ and the reference $R$ are in a pure joint stabilizer
state. The **code dimension** is

$$
k_C = S(R),
$$

in bits. By purity $S(R) = S([n])$. The system's state is maximally mixed on
the $2^{k_C}$-dimensional code space of its stabilizer group $S$, which has
$s = n - k_C$ independent generators, so $k_C$ is the number of logical
qubits of the code $C$, and $k_C/n$ its rate.

* **Purification picture** (`reference="purification"`): system qubit $i$ starts
  Bell-paired with reference $n + i$, so $k_C = n$ at layer 0.
* **Single picture** (`reference="single"`): one reference qubit, Bell-paired
  with a system qubit (fixed, or drawn per trajectory), so
  $k_C \in \lbrace 0, 1\rbrace$. Whether $k_C = 1$ says whether that one
  qubit of information is still protected.
* **No reference** (`reference="none"`): there is no code dimension; the probe
  is refused.

$k_C$ never increases: gates act on the system only, and a measurement on the
system cannot increase the entanglement between the system and $R$ (§2 shows
that it lowers $k_C$ by exactly one or leaves it unchanged). The
**purification layer** $\tau$ is the first checkpoint at which $k_C = 0$; after
it the reference stays pure. `EnsembleResult.purification_layer` records it
(-1 when the reference never purified within the horizon: right-censored),
and `EnsembleResult.survival()` gives $\Pr[\tau \gt L] = \Pr[k_C(L) > 0]$ at
the checkpoints. The purification time and its censoring are covered in
[HOW_IT_WORKS.md §8](../HOW_IT_WORKS.md#8-the-ensemble-engine) and in
[AGENTS.md](../../AGENTS.md#the-protocol-behind-run_ensemble).

## 2. What the simulator evaluates, and why it equals the definition

For a pure stabilizer state with stabilizer group $G$ (generated by the
tableau rows) and any set $X$ of qubits,

$$
S(X) = \operatorname{rank}(G|_X) - |X|,
$$

where $\operatorname{rank}(G|_X)$ is the rank of the $2|X|$ columns of $X$ over
the generators (Fattal et al., quant-ph/0406168). With $X = R$, this is what
any `Simulator` computes (`simulator.py::Simulator.entropy`, through
`observables.py::code_dimension`). The engine avoids the elimination by
keeping a basis adapted to $R$.

**The reference-row invariant.** Call a stabilizer row *marked* if it has
support on $R$; the engine keeps the marked rows as a bitset `ref_rows`.
Invariant: *the R-parts of the marked rows are linearly independent.* Given
it:

* $\operatorname{rank}(G|_R)$ is the number of marked rows (the unmarked rows
  have zero R-part), so
  $k_C = S(R) = \mathrm{popcount}(\text{marked}) - |R|$;
* the unmarked rows have no support on $R$, so they lie in $S$. There are
  $(n + |R|) - (|R| + k_C) = n - k_C = s$ of them, and they are independent, so
  they are a basis of $S$;
* all rows restricted to the system span $N(S)$
  ([random-region-erasure.md](random-region-erasure.md) §2.2).

**Why the invariant holds.** Right after the Bell pairing it holds: in the
purification picture the marked rows are $X_iX_{n+i}$ and $Z_iZ_{n+i}$, with
independent R-parts $X_{n+i}$, $Z_{n+i}$. `_kernel/entropy.py::reference_rows`
records them. Afterwards:

* **Gates** act on system columns only, so no row's R-part changes.
* **A measurement** of $Z_q$ on a system qubit
  (`_kernel/tableau.py::measure_1q_phase_free_tracked`) finds the rows that
  anticommute with $Z_q$. If there are none, the outcome is deterministic and
  nothing changes. Otherwise the pivot is the **first anticommuting row
  outside `ref_rows`**, if there is one. Multiplying it into the other
  anticommuting rows leaves every R-part unchanged (its own is zero), and it
  is replaced by $Z_q$, which has no R-part either. The marked set and its
  R-parts are unchanged.
* If **every anticommuting row is marked**, the pivot is the first of them.
  Multiplying it into the other anticommuting marked rows replaces their
  R-parts $r_i$ by $r_i + r_p$. These stay nonzero and, together with the
  untouched marked rows, independent. The pivot row becomes $Z_q$ and leaves
  the marked set (its bit is cleared).

Either way the stabilizer group is the same as with the plain lowest-index
pivot of `measure_1q_phase_free`; only the generators differ. The popcount
drops by exactly one in the last case and is unchanged otherwise.

**Which measurements lower $k_C$.** The anticommuting rows are all marked
exactly when $Z_q$ commutes with $S$ (the unmarked rows) but not with all of
$N(S)$ (all rows restricted to the system). That means $Z_q$ is a nontrivial
logical operator. So $k_C$ drops by one exactly when the measurement measures
a logical Pauli of the current code. It is unchanged when $Z_q \notin N(S)$
(the code changes, its dimension does not), and when $Z_q \in S$ (a
deterministic outcome).

**A saved code.** `codes.py::StabilizerCode` has no reference qubits. Its
`num_logical` is $n - \operatorname{rank}(H)$ (`num_stabilizers` is the rank,
computed by `_kernel/entropy.py::symplectic_complement`), which is the same
$k_C$ by $k_C = n - s$.

## 3. From the kernel to the code you run

**Data layout.** The tableau `tab` holds an X and a Z bitset per qubit over
the generators (`tab[2q]`, `tab[2q + 1]`), and `ref_rows` is one more bitset
of $W = \lceil (n + |R|)/64\rceil$ words
([random-region-erasure.md](random-region-erasure.md) §3.1).

**The engine** (`_kernel/ensemble.py`):

1. `_setup` Bell-pairs the references (an H, then a CX), and
   `reference_rows(tab, ws, refs, ref_rows)` marks the rows touching $R$.
2. Every random measurement of the dynamics goes through
   `measure_1q_phase_free_tracked`, which maintains `ref_rows`.
3. At each checkpoint, `run_ensemble` reads
   `s_ref = popcount(ref_rows) - n_ref` once ($O(W)$ word operations).
   `eval_probe` writes it for a `code_dimension` probe (`row[0] = s_ref`), and
   passes it to the erasure probes, which return their trivial values when it
   is 0.
4. At the spec's own checkpoints, the first layer with `s_ref == 0` is the
   purification layer. With `stop_when_purified` the trajectory ends there,
   and its later `code_dimension` evaluations hold 0, the exact value
   (`mipt.py::_KINDS`).

`code_snapshot_rows` writes out exactly the unmarked rows, so a
`code_snapshot` probe records $n - k_C$, and `EnsembleResult.code(t, c)` returns
a `StabilizerCode` with `num_logical` $= k_C$.

**Python and JSON.**

* `mipt.code_dimension(*, checkpoints=None)`: `values["code_dimension"]` has
  shape `(trajectories, evaluations)`. `EnsembleResult.mean("code_dimension")`
  is the mean $k_C$ (divide by $n$ for the mean rate), and `survival()` the
  fraction with $k_C > 0$.
* `observables.code_dimension(sim, reference)` on any `Simulator`: the generic
  $S(R)$.
* `StabilizerCode.num_logical`, `StabilizerCode.from_simulator(sim, reference)`.
* JSON (CLI, MCP): the probe `{"kind": "code_dimension"}`, and for a single
  circuit the observable `{"kind": "code_dimension", "reference": "16:32"}`.
  The ensemble summary gives its mean and standard error per checkpoint, and
  a `purification` block with the censored fraction and the survival curve.

## 4. Cost and accuracy

* $k_C$ is an exact integer. In the engine it costs one popcount over $W$
  words per checkpoint. The generic $S(R)$ costs one elimination of
  $2\min(|R|, N - |R|)$ bitsets of $W$ words ($N$ qubits in all).
* Across trajectories, `analysis.mean_and_error` gives the mean and its
  standard error. The survival curve is exact at the checkpoints: every
  trajectory is observed up to the last one, and censoring affects only later
  layers. To combine runs with different horizons, use
  `analysis.kaplan_meier` (AGENTS.md, Pitfalls).

## 5. Worked example

A Watts–Strogatz circuit with $n = 16$ in the purification picture, with
$k_C$ recorded after every layer. The engine's popcount is compared with the
generic entropy of the replayed state at every `TICK`. It is also compared
with an independent numpy rank of the stabilizers restricted to $R$, and with
the saved code. The printed numbers depend on the version's random streams
and are not quoted.

```python
import numpy as np

from sparsegf2 import Simulator, StabilizerCode, graphs, mipt, observables

n = 16
spec = mipt.MonitoredCircuit(
    num_system=n,
    edges=graphs.watts_strogatz(n, 4, 0.1, seed=1),
    layers=64,
    measurement_rate=0.1,
    schedule="random_edges",
    reference="purification",
    checkpoints="every_layer",
    probes=[mipt.code_dimension(), mipt.code_snapshot(checkpoints="final")],
)
res = spec.run(8, seed=7)
k = res.values["code_dimension"].astype(int)  # (8 trajectories, layers 0..64)
assert np.all(k[:, 0] == n)  # n logical qubits after the Bell pairing
assert np.all(np.diff(k, axis=1) <= 0)  # k never increases
layers, surviving = res.survival()
assert np.array_equal(surviving, (k > 0).mean(axis=0))  # P(tau > L) = P(k(L) > 0)

t = 0
print("k after each layer:", k[t].tolist())
refs = spec.reference_qubits
sim = Simulator(spec.num_qubits, phases=False)
run = sim.run(spec.circuit(t, seed=7), observe=lambda s, tick: observables.code_dimension(s, refs))
assert [value for _, value in run.observations] == k[t].tolist()
```

The brute force: $S(R) = \operatorname{rank}(G|_R) - |R|$ with an independent
GF(2) rank, from the replayed state's stabilizer rows. The saved code has
$n - k_C$ generators. Finally the reference rows: in the replayed
`Simulator`, which uses the plain pivot rule, the number of rows touching $R$
is at least $|R| + k_C$ and can be larger. The engine's pivot rule keeps it
equal, which is what makes $k_C$ a popcount.

```python
def gf2_rank(vectors):
    """Rank over GF(2) of integers read as bit vectors."""
    basis = []  # distinct leading bits, in decreasing order
    for v in vectors:
        for b in basis:
            v = min(v, v ^ b)  # clears b's leading bit from v if v has it
        if v:
            basis.append(v)
            basis.sort(reverse=True)
    return len(basis)


xs, zs, _ = sim.stabilizer_arrays()  # one row per generator of the whole state
on_r = np.concatenate([xs[:, refs], zs[:, refs]], axis=1).astype(np.int64)
s_r = gf2_rank(int(row) for row in on_r @ (1 << np.arange(2 * len(refs)))) - len(refs)
assert s_r == k[t, -1]
assert res.values["code_snapshot"][t, 0] == n - k[t, -1]
assert res.code(t, 0).num_logical == StabilizerCode.from_simulator(sim, refs).num_logical == k[t, -1]

touching = int(on_r.any(axis=1).sum())
print(f"rows touching R in the replayed Simulator: {touching}; |R| + k = {len(refs) + k[t, -1]}")
assert touching >= len(refs) + k[t, -1]
```

In the single picture $k_C \in \lbrace 0, 1\rbrace$, so the survival curve is
the mean of $k_C$, and the purification layer is the first layer with
$k_C = 0$:

```python
single = mipt.MonitoredCircuit(
    num_system=n,
    edges=graphs.watts_strogatz(n, 4, 0.1, seed=1),
    layers=64,
    measurement_rate=0.1,
    schedule="random_edges",
    reference="single",
    checkpoints="every_layer",
    probes=[mipt.code_dimension()],
)
r1 = single.run(200, seed=7)
k1 = r1.values["code_dimension"]
assert set(np.unique(k1)) <= {0.0, 1.0}
layers, surviving = r1.survival()
assert np.array_equal(surviving, k1.mean(axis=0))
first_zero = np.where((k1 == 0).any(axis=1), np.argmax(k1 == 0, axis=1), -1)
assert np.array_equal(r1.purification_layer, first_zero)  # -1: never purified
```

## 6. Pitfalls

* **$k_C$ is about the reference pictures.** Without a reference there is no
  code dimension. On a `Simulator` you build yourself,
  `observables.code_dimension(sim, R)` is just $S(R)$; it is a code dimension
  only if the system and $R$ together are in a pure state.
* **Single picture.** $k_C \le 1$, and with `reference_partner="random"` the
  protected qubit differs between trajectories. The mean $k_C$ is the fraction
  of trajectories not yet purified, not a code rate.
* **Means include zeros.** `mean("code_dimension")` averages over all
  trajectories, purified ones contributing 0. That is right for the mean rate.
  For statistics of the codes themselves, condition on $k_C > 0$.
* **Purification is tested at the spec's checkpoints only.** A probe's own
  `checkpoints` never move $\tau$. With a coarse checkpoint stride, $\tau$ is
  the first checkpoint at or after the true purification layer.
* **Do not average $\tau$ with the censored $-1$ entries.** Use the survival
  curve, `censored_fraction` in the summary, or `analysis.kaplan_meier`
  (AGENTS.md, Pitfalls).
